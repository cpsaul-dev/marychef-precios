# marychef-precios

Data-only repo: a filtered daily snapshot of Austrian supermarket prices (BILLA, SPAR, HOFER, LIDL) for the Marychef app.
Source: [heisse-preise](https://github.com/badlogic/heissepreise) (MIT), `https://heisse-preise.io/data/latest-canonical.json`.
Files: `prices_at.json` (the snapshot) and `meta.json` (date and counts). No app code, no personal data.
