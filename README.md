# marychef-precios

Data-only repo: a filtered daily snapshot of Austrian supermarket prices (BILLA, SPAR, HOFER, MPREIS, UNIMARKT) for the Marychef app.
Source: [heisse-preise](https://github.com/badlogic/heissepreise) (MIT), `https://heisse-preise.io/data/latest-canonical.json`.
Files: `data/<store>.json` (one compact file per supermarket: BILLA, SPAR, HOFER, MPREIS, UNIMARKT; LIDL is not in the source) and `data/meta.json` (date, columns and counts). No app code, no personal data.
